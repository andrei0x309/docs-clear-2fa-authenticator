## Purpose

The purpose of this browser extension is to provide a convenient and user-friendly way to manage and protect your online accounts by implementing a two-factor authentication (2FA) system.

## Features

- **Shortcut Paste**: Paste your 2FA codes using a keyboard shortcut (Ctrl + Q) for quick access.
- **Simple Interface**: Enjoy a clean and intuitive interface that makes managing your 2FA codes effortless.
- **Right-Click Context Menu**: Paste your 2FA codes directly from the right-click context menu for added convenience.
- **Search**: Easily find your 2FA codes with a powerful search feature that saves you time.
- **Dark Mode**: Switch to dark mode for a comfortable viewing experience, especially in low-light environments.
- **Privacy**: Your 2FA codes are encrypted and stored locally, ensuring your privacy and security.
- **Open Source**: The source code for this extension is available on GitHub, allowing you to contribute, report issues, and improve the extension.
- **Export**: Export your 2FA codes to a JSON or as a ZIP containing all QR codes for easy backup and sharing.
- **Import**: Import your 2FA codes from a JSON file.
- **Add New Account**: Add a new account to the extension, by manually providing the data or by uploading a QR or by scanning the QR code on the current page/tab.
